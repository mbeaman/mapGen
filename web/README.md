# mapgen-web

Browser frontend for the `mapgen` fantasy-map generator. Drives the
`mapgen-wasm` crate through wasm-pack output; no backend.

## One-time setup

```sh
# from repo root
cargo install wasm-pack    # if missing
cd web
npm install                # pnpm and yarn work identically
```

## Dev loop

```sh
cd web
npm run build:wasm         # build crates/mapgen-wasm → web/pkg
npm run dev                # vite on http://localhost:5173
```

`build:wasm` runs `wasm-pack build --target web` against
`crates/mapgen-wasm` and writes the ES module + .wasm into `web/pkg/`.
Vite picks it up via the relative import in `src/main.ts`.

Rebuild the wasm whenever Rust changes; Vite HMR picks up TS/CSS/HTML
changes automatically.

## Production build

```sh
npm run build              # type-check + vite build → web/dist
npm run preview            # serve dist locally
```

## Layout

```
web/
├── index.html             # single page, form + map div
├── package.json
├── tsconfig.json
├── vite.config.ts
├── src/
│   ├── main.ts            # init wasm, wire form to generate/render
│   └── style.css
└── pkg/                   # generated by wasm-pack (gitignored)
```

## API used

The WASM crate exports two operations:

* `generate(seed, cells, nations) -> WorldHandle` — slow (~5 s at 15 k
  cells); runs the full geography → climate → biomes pipeline.
* `WorldHandle::render(style) -> string` — cheap (~1 s); style is
  `"greyscale" | "biomes" | "cultures" | "ornate"`. Call it repeatedly
  to switch styles on a generated world without regenerating.
