# mapgen-web

Browser frontend for the `mapgen` fantasy-map generator. Drives the
`mapgen-wasm` crate through wasm-pack output; no backend.

## Features

* **Off-thread generation.** The WASM runs in a WebWorker
  (`src/worker.ts`), so the slow generate pass never freezes the UI. An
  animated overlay shows elapsed time.
* **Cheap re-styling.** A generated world is held in the worker as a
  `WorldHandle`; changing style re-renders without regenerating.
* **Pan / zoom.** Drag to pan, wheel to zoom (anchors on the cursor),
  double-click or the ⤢ button to fit. See `src/panzoom.ts`.
* **Export.** Download the map as SVG, or rasterise to a 2× PNG
  client-side (embedded fonts are preserved in both).
* **Permalinks.** Seed / detail / nations / style live in the URL query;
  "Copy link" reproduces the exact map. The page autoloads from the URL
  (or a default) on first paint.

## One-time setup

First install **Node 18+ and npm** (apt / brew / nvm — not
cargo-installable). Then, from the repo root:

```sh
just web-setup    # installs wasm-pack (via cargo), runs npm install, builds web/pkg
```

Equivalent by hand:

```sh
cargo install wasm-pack    # if missing
cd web
npm install                # pnpm and yarn work identically
npm run build:wasm
```

## Dev loop

```sh
just web-dev      # Vite dev server → http://localhost:5173
just web-build    # rebuild web/pkg after Rust changes
```

Or directly: `cd web && npm run dev` / `npm run build:wasm`.

`build:wasm` runs `wasm-pack build --target web` against
`crates/mapgen-wasm` and writes the ES module + .wasm into `web/pkg/`.
Vite picks it up via the relative import in `src/main.ts`.

Rebuild the wasm whenever Rust changes; Vite HMR picks up TS/CSS/HTML
changes automatically.

## Production build

```sh
npm run build              # type-check + vite build → web/dist
npm run preview            # serve dist locally
```

## Layout

```
web/
├── index.html             # single page: controls + map viewport
├── package.json
├── tsconfig.json
├── vite.config.ts
├── src/
│   ├── main.ts            # UI orchestration: worker, export, permalink
│   ├── worker.ts          # holds the WASM + WorldHandle off-thread
│   ├── panzoom.ts         # cursor-anchored pan/zoom on the map
│   ├── style.css          # parchment theme (reuses the map's fonts)
│   └── fonts/             # Cinzel + EB Garamond + IM Fell (UI chrome)
└── pkg/                   # generated by wasm-pack (gitignored)
```

## API used

The WASM crate exports two operations:

* `generate(seed, cells, nations) -> WorldHandle` — slow (~5 s at 15 k
  cells); runs the full geography → climate → biomes pipeline.
* `WorldHandle::render(style) -> string` — cheap (~1 s); style is
  `"greyscale" | "biomes" | "cultures" | "ornate"`. Call it repeatedly
  to switch styles on a generated world without regenerating.
